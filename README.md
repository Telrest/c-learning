# C 学习记录

从零开始学习 C 语言，保存练习代码、问题和解决过程。

## 当前状态

这是学习环境的初始化仓库。初始配置、示例和文档由 AI 协助准备，不代表我已经独立完成相关学习。后续提交记录实际练习与理解。

## 在 Windows 上开始

需要 VS Code、微软 C/C++ 扩展，以及 MSYS2 UCRT64 的 GCC 与 GDB。当前工具链位于 C:/msys64/ucrt64/bin，使用 C11 标准。

1. 在 VS Code 中打开整个 `c-learning` 文件夹。
2. 打开 `examples/01-hello/main.c`，操作运行或调试前保持该 C 文件为活动文件。
3. 按 `Ctrl+Shift+B` 编译，查看终端中的结果。
4. 按 `Ctrl+F5` 编译并运行。需要输入时在下方终端输入。
5. 调试时，在代码行号左侧点击设置断点，按 `F5` 开始，按 `F10` 逐行执行，按 `Shift+F5` 停止。

首次选择运行配置时，选 `C: debug active file (GCC + GDB)`。Ctrl+F5 运行，F5 调试；Ctrl+Shift+B 默认编译带调试信息的版本。输入仍在集成终端中进行。

当前配置用于单个 C 文件练习，不会自动组合多个源文件。生成的 .exe 与当前 .c 文件放在同一文件夹，已由 .gitignore 排除，不上传。若程序还在运行，先停止再重新编译。

## 第一次练习

- 运行示例，确认出现两行文字。
- 自己修改其中一句，再运行，观察结果是否改变。
- 新增一条 `printf`，用自己的话解释 `\n` 的作用。
- 故意删除一个分号，观察编译报错，然后修复。
- 完成后复制 `notes/template.md` 为自己的日期记录，写下实际学到的内容。

后续可在 `exercises/` 下建立自己的练习子目录。不要提交学号、账号密码、激活码或有个人信息的截图，也不要上传教材全文。

## 用 GitHub 记录进步

每完成一个能运行的小练习或修复一个实际问题，就可以提交一次，无需为了连续打卡制造空提交。

在 VS Code 左侧“源代码管理”（`Ctrl+Shift+G`）：

1. 点开变更文件，检查自己改了什么。
2. 点击文件旁的 `+` 暂存。
3. 写明提交内容，例如“练习：使用 printf 输出三行文字”。
4. 点击“提交”，再点击“同步更改”或“推送”。

在网页上打开仓库，即可看到代码、提交记录和学习笔记。
